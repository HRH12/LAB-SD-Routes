# Networking Lab: Static & Default Routing Practice

## Lab Overview
This lab focuses on foundational routing concepts, specifically **default routes** and **static routes**. I configured a small network topology where all IP addresses are assigned statically, and full end-to-end connectivity must be achieved through proper routing configuration.

## Lab Objectives
- Configure **static IP addressing** on all devices (no DHCP)
- Create and configure **static routes**
- Configure a **default route** where appropriate
- Ensure **end-to-end connectivity across the entire topology**
- Secure the network by **shutting down unused ports**
- Update and assign **proper hostnames to all network devices**
---

## Key Skills Practiced

- Static IP configuration
- Static routing implementation
- Default route configuration (`0.0.0.0/0`)
- Basic network security hardening
- Switch port management
- Network troubleshooting and validation
- Device naming conventions

---

## Expected Outcome

By the end of this lab, the network should:

- Have full connectivity between all endpoints
- Route traffic correctly using static and default routes
- Be secured by disabling unused interfaces
- Follow clear and consistent device naming standards

## Notes

Take time to verify each configuration step. If connectivity fails, troubleshoot routing tables, interface status, and IP addressing first.
